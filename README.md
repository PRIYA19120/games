# 🎮 Games Collection

A collection of simple and interactive games developed using C programming.

## 🎯 Games Included

### 1. KBC Quiz
A quiz game inspired by Kaun Banega Lakhpati where players answer multiple-choice questions and win money for correct answers.

### 2. Rock Paper Scissors
A simple Rock Paper Scissors game where the player competes against the computer.

### 3. Truth and Dare
A fun Truth and Dare game that randomly generates a truth question, dare, or safe option.

### 4. Tic Tac Toe
A two-player Tic Tac Toe game played on a 3×3 board.

## 🛠️ Technologies Used

- C Programming
- GCC Compiler
- Git & GitHub
